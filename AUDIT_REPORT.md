# QA-аудит — v9

## Что проверено статически
- JavaScript `index.html`: синтаксис проходит `node --check`.
- JavaScript `admin.html`: синтаксис проходит `node --check`.
- Дублирующиеся HTML `id`: не обнаружены.
- Дублирующиеся объявления `function`: не обнаружены.
- `eval()` и `document.write`: не используются.
- Отзывы читаются из Supabase отдельно от получения anonymous session; публичное чтение больше не блокирует открытие карточки.
- Добавлен in-memory cache отзывов и prefetch при hover/focus/touch.
- Исправлен порядок вывода последних отзывов: показываются новые, а не хвост старых записей.
- Уменьшены тяжёлые эффекты у detail overlay в тёмной теме.

## Что сознательно не делалось
- Реальная DDoS/бот-атака на production не выполнялась.
- Агрессивное нагрузочное тестирование Supabase не выполнялось.
- Массовый рефакторинг рабочего кода не выполнялся, чтобы не повышать риск регрессий.
- Полноценный browser E2E не заявляется, если он не был успешно запущен в среде.
