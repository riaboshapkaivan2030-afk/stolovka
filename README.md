# Столовка лицея — версия с обновлённой админкой

Что изменено:

- полностью переработана визуальная часть `admin.html` в тёплой осенней стилистике;
- на главном экране админки убрана средняя оценка, вместо неё показано количество блюд в наличии;
- для карточек блюд добавлена библиотека иллюстративных фото еды из Unsplash;
- если у блюда нет своего `image_url`, админка показывает подходящую фотографию по названию/категории;
- в форме блюда добавлены поле URL изображения и кнопка «Подобрать фото»;
- при сохранении блюда автоматически подобранная фотография может записываться в `image_url`;
- на `index.html` полностью удалена история цен и зависимость от Chart.js;
- в разделе «Фишки» случайное одиночное блюдо заменено на комбо: основное + гарнир + напиток;
- убраны неподтверждённые «меню дня» и примерное расписание приёмов пищи;
- добавлены проверенные сведения о МАОУ «Многопрофильный лицей»: г. Муравленко, ул. Пионерская, 4, официальный сайт `https://murlicey.yanao.ru`;
- фотографии блюд являются иллюстративными и не означают точный внешний вид блюда в столовой.

Проверки перед упаковкой:

- JavaScript `index.html` — `node --check` без синтаксических ошибок;
- JavaScript `admin.html` — `node --check` без синтаксических ошибок;
- дублирующихся HTML `id` не обнаружено;
- упоминания истории цен и средней оценки на главном экране админки удалены.
